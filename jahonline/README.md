# JAHOnline-palvelimen iltarasti-tiedostot

JAHOnline-sivuston PHP ei ole tässä repossa. Tässä kansiossa on
palvelimelle vietävät JS/CSS-tiedostot Automaatti-näyttöä ja
rastiväliaikojen rastitilanne-grafiikkaa varten.

Kopioi Hetznerille (`/var/www/jahonline`) skriptillä `deploy.sh`.
Välimuistiversio: `20261111net`, PWA-välimuisti `jahonline-app-v17`.
Automaatti avautuu `/public/automaatti.php` koko näytön kioskina.
